Creates a new support ticket. Requirements:
- Ticket system must be enabled in `ticket_settings` (403 if not).
- `department` must match one of the configured departments in `ticket_settings.departments` (422 if not).

On success, an in-app notification is sent to every admin user.

**Required permission:** `tickets.create`
