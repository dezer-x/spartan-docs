Changes ticket status to any valid value. Returns 400 if already at the requested status.

A status-change notification with a contextual message is sent to the ticket owner and any `extra_user_ids`.

| New status | Message sent | Notification type |
|---|---|---|
| `closed` | Your ticket has been closed. | success |
| `resolved` | Your issue has been resolved. | success |
| `answered` | Support team has responded. | info |
| `awaiting` | Your ticket is awaiting your response. | warning |
| `open` | Your ticket has been reopened. | info |

**Required permission:** `tickets.update`
