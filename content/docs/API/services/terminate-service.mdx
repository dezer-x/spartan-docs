Terminates the service. Behaviour depends on current status:

| Current status | Outcome |
|---|---|
| `terminated` | Hard-deleted immediately. Returns 200. |
| any other | Module `DeleteServerService::deleteServer()` called if module exists. Success → status set to `terminated`. Failure → hard-deleted locally, returns 400. |

**Required permission:** `services.terminate`
