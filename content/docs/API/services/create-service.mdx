Creates a new service. Two modes based on `service_type`:

**`product` mode** — links to an existing product. If `billing_cycle` is supplied it must exist in the product's `duration_config` and have `enabled: true`.

**`custom` mode** — fully manual service, not attached to any module.

**Required permission:** `services.create`
