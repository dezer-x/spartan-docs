# Installation

Installing **DezerX Spartan** is quick and straightforward. With a single command, you can deploy the entire billing system on a **fresh Linux server**.
### One Command Installation

Connect to your server via SSH and run the following command:

```bash
sudo bash -c "$(curl -fsSL https://github.com/dezerx-spartan/Spartan-Installer/releases/latest/download/spartan_installer.sh)"
```


### Before You Begin

Ensure that:

* You are using a **fresh VPS or dedicated server** to avoid any conflict ( Optional but Recommended )
* The server runs a **supported Linux distribution**
* You have **root or sudo access**
* Your server has an active **internet connection**
