# Updating

There are several ways you can update DezerX Spartan. First is our built in auto updater which you can 
### One Command Updating

Connect to your server via SSH and run the following command:

```bash
sudo bash -c "$(curl -fsSL https://github.com/dezerx-spartan/Spartan-Installer/releases/latest/download/spartan_installer.sh)" -- --non-interactive --update --app-dir="/var/www/directory"
```


### Before You Begin

Ensure that:

* Make sure you have the correct directory inside --app-dir="/var/www/directory".
* Have enough available resources on the server.
* You have **root or sudo access**
* Your server has an active **internet connection**
