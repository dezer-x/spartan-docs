# Introduction
DezerX Spartan is a billing software developed and designed in 2024. It offers an affordable solution with a clean, modern user interface and a wide ecosystem of modular extensions. Built in PHP, DezerX Spartan is designed for flexibility, scalability, and ease of use.

## Key Features

* **Modern & User Friendly Interface**
  DezerX Spartan features a clean, intuitive UI designed to feel great out of the box no additional themes required. It includes extensive customization options such as color schemes, seasonal themes, and layout preferences to match your brand.

* **Security First Architecture**
  Built with security as a top priority, DezerX Spartan ensures your data, users, and transactions are protected using industry best practices.

* **Modular & Easily Extendable**
  Built on a modular architecture, DezerX Spartan allows you to easily create and integrate custom modules to fit your business needs.

## Supported Operating Systems

DezerX Spartan is designed to run on **Linux-based server environments only**.

| Operating System | Supported | Notes           |
| ---------------- | --------- | --------------- |
| Ubuntu (20.04+)  | ✅ Yes     | Recommended     |
| Debian (11+)     | ✅ Yes     | Fully supported |
| AlmaLinux (8+)   | ✅ Yes     | Fully supported |
| Rocky Linux (8+) | ✅ Yes     | RHEL-compatible |
| CentOS Stream    | ✅ Yes     | Supported       |
| Windows Server   | ❌ No      | Not supported   |
| macOS            | ❌ No      | Not supported   |
