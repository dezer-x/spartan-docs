---


## Step 1: Create a VirtFusion API Key

1. Log in to your **VirtFusion** admin panel.
2. Navigate to **System → API**.
3. Click **Create Token**.
4. Follow the prompts, then click **Next**.
5. Copy the generated API token and keep it safe.

## Step 2: Configure DezerX

1. Open the **DezerX Admin Panel**.

2. Enter the following details:

   * **VirtFusion API Key** (the token you copied earlier)
   * **VirtFusion URL** (your VirtFusion installation URL)

   Example:
   ![VirtFusion Configuration](/VirtFusion/image-1.png)

3. Click **Test Connection** to verify that DezerX can successfully connect to VirtFusion.

✅ If the test succeeds, your VirtFusion integration is complete and ready to use.
