## Configure cPanel API Access
1. **Log into your WHM** using your administrator credentials.
2. Get API Credentials in "Manage API tokens" tab.
![IMG](/services/cpanel/step-1.png)

---

## Configure API in DezerX Spartan
1. Go on your market, and log in using administrator account
2. Go to Admin -> Modules -> Services
3. Click on cPanel.
4. Create a server & fill in details.
![IMG](/services/cpanel/step-2.png)

---

## Configure product in DezerX Spartan
1. Go in Products and create a product with cPanel module
2. Select a server ( cPanel host ) & a package from the dropdown menu.
![IMG](/services/cpanel/step-3.png)
