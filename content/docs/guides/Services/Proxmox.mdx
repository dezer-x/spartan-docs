## Get the Proxmox API Token

1. Log in to your **Proxmox** panel.
2. Navigate to the API token creation page.
3. Make sure **Separate Privileges** is **enabled**.  
   ![Enable Separate Privileges](/services/proxmox/step-1.png)
4. Click **Next**, then copy both the **User Token** and **Secret**.  
   ![Copy Token and Secret](/services/proxmox/step-2.png)

## Configure DezerX

1. Open the **Proxmox module** in the **DezerX Admin Panel**.
2. Create a new **Location** using your Proxmox API token and secret.  
   ![Create Location in DezerX](/services/proxmox/step-3.png)

<Callout type="info" >Once saved, your DezerX setup is ready to connect to Proxmox.
Please make sure your proxmox is on the same domain as your billing and has SSL.</Callout>
